## Deviations from the plan

- No bash guest: sharrattj/bash crashes and coreutils fails to download in @wasmer/sdk 0.13, so run_shell only translates echo/cat/ls/pwd to Python.
- Node guest needs `--experimental-wasm-jspi`, and Node refuses it in NODE_OPTIONS, so the gateway is launched with `node` directly.
- Memory limits are recorded on the policy but not enforced (no SDK option).
- Browser replay was dropped; the console is read-mostly with a run form.
